Installer sur le téléphone

  1. Appuyez sur « Télécharger l'application ».
  2. Ouvrez le fichier téléchargé.
  3. Si Android bloque : Paramètres → Sécurité → Sources inconnues, autorisez le navigateur, puis revenez.
  4. Appuyez sur Installer.
  5. Au premier lancement, indiquez l'adresse du serveur ci-dessous.
